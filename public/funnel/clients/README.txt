HOW TO ADD A PHOTO
- Drop a file here named exactly as listed below, using .jpg.
- Square-ish images look best (they're cropped to a circle, center-filled).
- ~200x200px or larger is plenty; keep files small for fast load.

  to the client's initials — nothing breaks.
